# techiitfly

Official website for **techiitfly** — Pune studio building websites and learning platforms for education and wellness businesses.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (Static Export / Turbopack)
- **Styling**: Tailwind CSS + Custom CSS Variables & Design System
- **Typography**: Instrument Serif, Plus Jakarta Sans, Geist, Geist Mono
- **Animation**: Framer Motion
- **Hosting**: Static Hosting / Vercel / GitHub Pages

## Development

```bash
# Install dependencies
npm install

# Run development server (port 3001)
npm run dev

# Build production static bundle
npm run build
```

## Structure

- `app/` — Next.js App Router pages and layouts
- `components/` — Modular UI components (Hero, Offers, Work, Guarantee, Lab, Products, FAQ, Contact)
- `content/` — Site settings, availability, project case studies, and audit logs
- `public/` — Static assets, icons, and real production captures
- `scripts/` — Automated Core Web Vitals audit receipts and tooling
